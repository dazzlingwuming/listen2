<interfaces>
Keep the existing host callback window.Listen2AndroidPlaybackBack and mutable handled event contract. The shared coordinator delegates to existing layer owners through broadcasts and local shell state; it returns false only when no transient or real child route consumed Back.

Back priority is exact: focused search/IME; open confirmation; queue/lyrics or other player child sheet; full player; Bilibili part/source detail/library/product sheet; real in-app child route; Activity.

The terminal CSS contract remains scoped to .modern-body at max-width 760px. Canonical geometry is --mobile-dock-height: 64px and --mobile-tabbar-height: calc(64px + env(safe-area-inset-bottom, 0px)); the content reserve adds both heights plus 24px.
</interfaces>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Android system Back to shared page | A native lifecycle event may close only the current trusted shell layer |
| Layer owner to navigation coordinator | Mutable handled events and cancellation must not cascade to sibling layers |
| Dynamic content to compact layout/accessibility tree | Untrusted long text must not obscure controls or expose unsafe copy |
| Mobile CSS to desktop UI | Phone overrides must remain scoped and must not rewrite desktop behavior |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-BACK | Tampering | handleAndroidPlaybackBack | high | mitigate | Enforce exact nearest-layer priority and one handled result through deterministic VM/source contracts |
| T-04-CANCEL | Denial of service | layer closure with active request | medium | mitigate | Broadcast owner cancellation before returning handled so hidden work cannot retain spinner or mutate later |
| T-04-NAV | Elevation of privilege | top-level/native fallthrough | high | mitigate | Add no external navigation or privileged operation; clean top-level Back returns to existing Activity policy |
| T-04-OVERLAY | Spoofing | overlapping sheet/player/tab surfaces | medium | mitigate | Reserve fixed surfaces and safe insets, bound sheet scrolling, and test compact/large-text geometry |
