## Trust Boundaries

| Boundary | Description |
|---|---|
| Classic-script provider → typed adapter | Legacy callback code supplies provider intent to a Promise/request-handle API. |
| Typed native result → provider domain objects | Safe DTO becomes search rows, part tracks, and player descriptor. |
| Descriptor → existing player callback | Signed short-lived candidates enter current-track memory. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-09 | Tampering | Adapter terminal settlement | high | mitigate | Epoch/request/terminal validation, delete-before-settle, explicit native cancellation, duplicate/late fixtures. |
| T-01-10 | Elevation | Selected part and entitlement mapping | high | mitigate | Exact explicit CID equality, provider capability state, no fallback or permission inference, fixture assertions. |
| T-01-11 | Information Disclosure | Provider failure/descriptor | high | mitigate | Stable safe error mapper and minimized descriptor; output/redaction tests exclude raw details. |
| T-01-12 | Denial of Service | Partial/malformed results | medium | mitigate | Bounded fixture/schema processing, optional-row isolation, one callback, finite candidates. |

ASVS L1 blocking rule: each high-severity threat must be closed by the named adapter/provider code and its negative test; an unverified descriptor, wrong-part fallback, raw-error path, or double settlement blocks completion.
