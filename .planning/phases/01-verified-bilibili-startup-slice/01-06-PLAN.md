## Trust Boundaries

| Boundary | Description |
|---|---|
| Typed descriptor → Howler/media element | Short-lived external media capability enters the foreground player. |
| Howler callbacks → visible playback state | Async/stale media events can claim user-visible success or failure. |
| Lyric provider callback → current track DOM | Independent external text/state can overwrite or disrupt playback UI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-21 | Spoofing / Repudiation | Playback success state | high | mitigate | Current token/track/CID plus measured forward progress; fake Howl tests and live AudioFlinger/UI proof. |
| T-01-22 | Tampering / Denial of Service | Candidate recovery | high | mitigate | Native-bounded list, MIME/codec check, finite ordered retries, current-only guards, exhaustion tests. |
| T-01-23 | Information Disclosure | Candidate/error scope and DOM | high | mitigate | No candidate/raw error on scope/DOM/logs; fixed copy and redaction assertions. |
| T-01-24 | Tampering | Stale lyric response | medium | mitigate | Track/token/cancel guard, mutually exclusive state reducer, no playback side effect, race tests. |

ASVS L1 blocking rule: false playback success, unbounded/stale candidate execution, or candidate/error disclosure is a high-severity blocker. Deterministic tests must close the code path and Plan 01-07 must still prove the installed runtime; neither can be waived.
