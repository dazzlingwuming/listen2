## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider/controller callbacks → Angular scope | Async current/stale/error data attempts visible state mutation. |
| Provider metadata → HTML/CSS sinks | External text/artwork/capability becomes rendered phone content. |
| User navigation/back → request lifecycle | UI gestures cancel or retain the current transaction and playback context. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-13 | Tampering / Spoofing | Stale controller callback | high | mitigate | Page epoch/query/detail guards, explicit handle cancellation, one scoped announcement, race tests. |
| T-01-14 | Elevation / Information Disclosure | Metadata and artwork sinks | high | mitigate | Native/provider allow-list plus Angular text bindings, HTTPS artwork/neutral fallback, hostile fixture tests. |
| T-01-15 | Repudiation | Capability/error presentation | medium | mitigate | Closed safe state/copy map, one current retry, source/capability labels, no empty-success coercion. |
| T-01-16 | Denial of Service | Remote startup/loading | medium | mitigate | Local first paint, bounded token deadline, terminal finalization, content preservation, missing-callback tests. |

ASVS L1 blocking rule: high-severity stale-state or executable/leaking sink behavior blocks completion until the exact current-identity guard, text-safe rendering, and negative fixtures pass; CSS/markup presence alone cannot downgrade either threat.
</threat_model>
