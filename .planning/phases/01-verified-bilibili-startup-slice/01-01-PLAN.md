## Trust Boundaries

| Boundary | Description |
|---|---|
| Packaged page → WebMessage listener | Semi-trusted classic JavaScript requests native capability. |
| Native contract → Bilibili HTTPS | Untrusted typed payload becomes a native-owned external request. |
| Bilibili JSON → packaged page | Untrusted external data becomes visible/searchable UI state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Spoofing / Elevation | WebMessage source and envelope | high | mitigate | Exact appassets main-frame/source-origin check plus protocol/request/epoch validation before dispatch; JUnit and JS negative cases. |
| T-01-02 | Elevation / Information Disclosure | Typed search dispatcher | high | mitigate | Closed operation and exact payload keys; native-only route/header construction; no raw body or transport fields in typed replies. |
| T-01-03 | Tampering / Denial of Service | Provider response projection | high | mitigate | Bounded body/rows/fields, exact schema and provider status, text-safe projection, HTTPS cover allow-list, stable safe errors. |
| T-01-04 | Repudiation | Duplicate/stale reply | medium | mitigate | `(pageEpoch, requestId)` correlation, delete-before-settle, duplicate and mismatch fixtures. |
| T-01-04A | Spoofing / Repudiation | API-35 runtime/evidence identity | high | mitigate | Explicit device selection, runtime package/API/WebView checks, APK/git identity fields, bounded instrumentation, and fail-closed Wave-0 evidence validation. |
