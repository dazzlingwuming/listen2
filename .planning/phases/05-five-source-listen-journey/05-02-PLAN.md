<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React Native controls → PlayerController | Rapid, stale or malformed semantic commands cross from UI into the sole playback coordinator. |
| Provider resolver → RNTP | Bounded media candidates and provider errors cross into the native playback library. |
| redux-persist storage → player state | Locally stored queue/history/mode/position may be legacy, corrupt, oversized or transport-contaminated. |
| RNTP service events → Redux snapshot | Remote/system callbacks can race with page commands and queue-ended/error callbacks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-02-01 | Spoofing / Elevation of privilege | `PlayerScreen`, `PlayerController`, RNTP | high | mitigate | UI emits closed semantic commands; only the configured controller imports RNTP and no second player/session is created. |
| T-05-02-02 | Tampering | Play-next occurrence and transition tokens | high | mitigate | Mint stable occurrence IDs, validate revision/token ownership, target mutations by occurrence and consume only after native success. |
| T-05-02-03 | Information disclosure | Persisted player state and Redux snapshots | high | mitigate | Versioned sanitizer admits semantic track/state fields only and rejects URLs, headers, cookies, signed media and native IDs. |
| T-05-02-04 | Denial of service | Rapid UI/system commands | medium | mitigate | Serialize conflicting commands, bound retry to the current occurrence and make queue-ended/remote callbacks exactly-once per transition token. |
| T-05-02-05 | Repudiation | Queue mutation result | low | accept | Deterministic occurrence IDs and accepted/rejected transaction results are sufficient for local UI recovery; no remote audit trail is needed. |
</threat_model>
