## Trust Boundaries

| Boundary | Description |
|---|---|
| Packaged page → playback command policy | Untrusted semantic source and identity fields enter native validation. |
| Resolver factory → provider manifest port | A validated source selects the only code allowed to acquire native media candidates. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01-01 | Tampering / Elevation of privilege | `PlaybackResolverFactory` | high | mitigate | Exact source switch, explicit unavailable default, and spy assertions that non-Bilibili sources cannot invoke the Bilibili supplier. |
| T-05-01-02 | Spoofing | `PlaybackBridgePolicy` logical identity | high | mitigate | Source-specific ID grammar, part, media-kind, and text bounds at both command and descriptor boundaries. |
| T-05-01-03 | Denial of service | Unsupported resolver recovery | medium | mitigate | Empty bounded candidate result, stable terminal code, and no queue advancement or retry loop. |
| T-05-01-04 | Information disclosure | Resolver state | medium | mitigate | Candidate and cookie values remain inside the service/resolver objects and never enter snapshot or test output. |
</threat_model>
