<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Provider response → TypeScript adapter | Untrusted remote JSON, metadata, pagination and error data enter normalized mobile DTOs. |
| Capability registry → React Native actions | Registry truth controls whether a user can dispatch search/detail/play/login/retry operations. |
| Navigation/restoration state → screen | Persisted or reconstructed semantic state may be stale, malformed, oversized or mismatched to the current source. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01-01 | Spoofing / Elevation of privilege | `PROVIDER_CAPABILITIES`, `TrackRow`, detail navigation | high | mitigate | Use a closed operation capability union and tests that unavailable/unknown operations cannot dispatch or navigate. |
| T-05-01-02 | Tampering | `SearchJourneyState` generations and cursor merge | high | mitigate | Validate source/query/kind/request identity, bound rows/pages, deduplicate semantic IDs, and ignore stale generations. |
| T-05-01-03 | Information disclosure | Provider error projection | high | mitigate | Map to fixed safe codes/actions; tests reject raw bodies, exceptions, signed URLs, headers, cookies and tokens in screen state. |
| T-05-01-04 | Denial of service | Search pagination/restoration | medium | mitigate | Retain existing request cancellation/deadlines, bound restored pages/rows/strings, and settle each generation once. |
| T-05-01-05 | Repudiation | Retry/cancel terminal attribution | low | accept | Semantic request IDs and deterministic terminal tests provide sufficient local attribution; Phase 5 adds no remote audit log. |
</threat_model>
