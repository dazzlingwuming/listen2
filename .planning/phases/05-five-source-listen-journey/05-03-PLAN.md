<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Provider/candidate reply → lyric session | Untrusted lyric text, translations, candidate metadata and errors race against occurrence/revision changes. |
| AsyncStorage → lyric selection | Persisted manual choice and offset may be stale, corrupt, oversized or mismatched to the current track/part. |
| Player snapshot → lyric projection/TalkBack | High-frequency position updates choose visible/current-line semantics and accessibility announcements. |
| Lyric UI → DeepSeek native boundary | User-provided lyrics/title/artist may leave the device only after complete consent; keys and responses stay protected. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03-01 | Tampering | `LyricSessionKey`, async replies, selection store | high | mitigate | Match source/track/part/occurrence/revision and expected storage revision before every mutation; cancel and reject stale callbacks. |
| T-05-03-02 | Spoofing | Fallback/manual/translation provenance | medium | mitigate | Render safe normalized provenance from closed enums and test that Bilibili fallback is labelled NetEase/QQ rather than native. |
| T-05-03-03 | Information disclosure | DeepSeek and lyric error/state projection | high | mitigate | Preserve native secret isolation, explicit consent, bounded DTOs and fixed safe errors; prohibit raw payload/response/key logging or persistence. |
| T-05-03-04 | Denial of service | Lyric parsing and TalkBack live announcements | medium | mitigate | Retain text/line/offset bounds and announce only active-line/session transitions, not position ticks. |
| T-05-03-05 | Elevation of privilege | Manual lyric and translation actions | high | mitigate | Gate operations through Plan 05-01 capability enums and existing closed native clients; no arbitrary URL/header/cookie/native method is representable. |
</threat_model>
