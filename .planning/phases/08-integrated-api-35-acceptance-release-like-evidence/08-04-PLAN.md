<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Evidence records -> parity claim | Missing, inconsistent or stale proof could be summarized as completion. |
| Tested APK -> handoff copy/device | Artifact substitution or wrong signer/device could invalidate all prior evidence. |
| Local install -> user data | Replacement/rollback/uninstall can affect persistent application data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-04-01 | Spoofing/Repudiation | Parity verdict | critical | mitigate | Exact 58-ID evidence reachability, common SHA/run validation and fail-closed status reducer. |
| T-08-04-02 | Tampering | APK handoff | critical | mitigate | Copy-by-hash, checksum, signer/package/version recheck and index binding. |
| T-08-04-03 | Information disclosure | Final report | high | mitigate | Closed schema, sanitized generation and final secret/artifact scan. |
| T-08-04-04 | Denial of service/Data loss | Install/rollback | medium | mitigate | Explicit serial, backup acknowledgement, replace-only default and documented prior-artifact recovery. |
| T-08-04-05 | Elevation | Release authority | high | mitigate | Development-signed naming, no formal credentials, and no merge/deploy/publish commands. |
| T-08-SC | Tampering | Package installs | high | mitigate | No package install occurs during finalization or handoff. |
</threat_model>
