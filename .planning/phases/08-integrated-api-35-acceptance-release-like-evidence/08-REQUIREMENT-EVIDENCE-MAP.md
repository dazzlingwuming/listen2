# Phase 8 Requirement Evidence-Kind Map

The finalizer consumes this checked-in 58-row map. Each runtime row adds: `implementationPaths[]`, `implementationBlobSha256[]`, `implementationCommit`, `evidenceRecordIds[]`, `artifactSha256[]`, and `status`. `implementationCommit` must be an ancestor of the run's exact current HEAD, every path must exist in `HEAD^{tree}`, and each recorded blob hash must equal the blob at current HEAD. A summary, old commit, or source-only claim cannot satisfy a required device/live/security/performance evidence kind.

Evidence kinds: `SOURCE_CONTRACT`, `CURRENT_HEAD_REACHABILITY`, `INSTRUMENTATION`, `API35_E2E`, `API35_ACCESSIBILITY`, `LIVE_PUBLIC_PROVIDER`, `CREDENTIAL_LIVE`, `SYSTEM_MEDIA`, `PERFORMANCE`, `RECOVERY_SOAK`, `APK_SECURITY`, `REPRO_BUILD`, and `FINAL_INDEX`.
