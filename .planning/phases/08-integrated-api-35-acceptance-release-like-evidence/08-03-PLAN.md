<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Test clock/system state -> metrics | Cherry-picked or invalid samples could fabricate acceptable p95 values. |
| Shell recovery actions -> device/app data | Process/network/settings mutations can corrupt state or leave the emulator unusable. |
| Resource/system dumps -> evidence | Dumps can contain identifiers, network details or provider text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-03-01 | Repudiation/Tampering | Performance samples | high | mitigate | Fixed sample counts, monotonic clocks, retained failures, deterministic percentile calculation and schema checks. |
| T-08-03-02 | Denial of service | Recovery/soak | medium | mitigate | Bounded cycles, explicit timeouts, cleanup traps and generated local media. |
| T-08-03-03 | Information disclosure | System dumps | high | mitigate | UID-scoped extraction, allow-listed fields, hashed serial and evidence redaction. |
| T-08-03-04 | Spoofing | API/device lane | medium | mitigate | Record `getprop` API/image/ABI and reject lane/API mismatch. |
| T-08-SC | Tampering | Package installs | high | mitigate | Required official SDK images must already be installed; missing images are `BLOCKED` with an explicit operator recovery command, and no application dependency is added. |
</threat_model>
