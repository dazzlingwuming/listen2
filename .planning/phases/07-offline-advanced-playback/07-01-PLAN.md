<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| JS -> native resolver | Untrusted semantic IDs, part/rendition choices, and request lifecycle cross into privileged provider code. |
| Native provider -> external CDN/API | Provider responses, redirects, entitlement and signed transport are untrusted network input. |
| TrackPlayer -> app content provider | A URI opens privileged native streaming bytes and must remain package/lease scoped. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-01-01 | Spoofing/Elevation | Resolver request | high | mitigate | Exact source/identity/account generation and native-returned part/rendition membership validation. |
| T-07-01-02 | Information disclosure | Descriptor bridge | critical | mitigate | App-owned URI plus ephemeral native lease; transport URLs, headers, cookies and candidates never serialize to JS. |
| T-07-01-03 | Tampering | CDN redirects/ranges | high | mitigate | HTTPS allow-lists, bounded candidates, redirect validation, MIME/length/codec and lease identity checks. |
| T-07-01-04 | Denial of service | Lease/stream registry | medium | mitigate | Bounded handles, TTL/use/read/candidate/deadline limits and cancellation cleanup. |
| T-07-SC | Tampering | Package installs | high | mitigate | No new npm/pip/cargo install; existing lockfiles remain authoritative and AndroidX additions are audited in RESEARCH.md. |
</threat_model>
