<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Logical page selection → native playback policy | Untrusted provider identity requests native-prepared playback. |
| Native resolver → Media3 | Transient authorized transport enters the sole player and must not escape. |
| Media3/service → page snapshot | Native identity and clock are projected through an allow-list. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-09 | Spoofing | `PlaybackBridgePolicy` selection identity | high | mitigate | Source-specific validation, native-minted opaque handles, expected revision, and replay-token checks. |
| T-03-10 | Information disclosure | Resolver/snapshot boundary | high | mitigate | Transient candidates stay native memory; recursive snapshot tests reject transport and credential material. |
| T-03-11 | Tampering | Lyric clock revisions | high | mitigate | Media3-only position, monotonic selection generation/revision, immediate discontinuity events, stale snapshot rejection. |
| T-03-12 | Denial of service | Foreground cadence | medium | mitigate | One 500 ms handler callback only while attached/active, cancelled on detach/idle/release, no persisted tick stream. |
| T-03-SC | Tampering | Package installation | low | accept | No dependency install; pinned Media3/Room versions remain unchanged. |
</threat_model>
