## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Typed provider/controller state → DOM | External safe text and capability/error state enter visible and accessible UI. |
| Native lyric snapshot → live region | Clock/state changes can trigger screen-reader speech. |
| Capability matrix → controls | Incorrect UI enablement could invoke unverified provider operations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-21 | Tampering | Angular provider/lyric sinks | high | mitigate | Text bindings only, safe fixed copy, no provider HTML or raw error/transport/internal identity. |
| T-03-22 | Elevation of privilege | Provider controls | high | mitigate | Default-unavailable matrix, disabled/static five-provider rows, current capability required for default play. |
| T-03-23 | Denial of service | TalkBack live region | medium | mitigate | One polite scoped region updated on semantic transitions only, never normal clock cadence/scroll. |
| T-03-24 | Spoofing | Loading/terminal UI | medium | mitigate | Mutually exclusive states, current identity guard, explicit visible copy plus `aria-busy`, one recovery action. |
| T-03-SC | Tampering | Package installation | low | accept | No package/registry installation; semantic HTML and existing CSS/runtime are reused. |
</threat_model>
