<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Shared provider/page code → native adapter | Page data is untrusted and must fit named semantic payloads. |
| Native reply → Angular/provider callbacks | Typed external failures and safe DTOs enter legacy callback/Promise surfaces. |
| Capability matrix → interactive UI | A false enabled bit could expose an unverified provider route. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-06 | Tampering | NetEase callback/status mapping | high | mitigate | Stable exhaustive terminal mapping; cancelled/stale replies cannot mutate a newer request or become empty success. |

| T-03-SC | Tampering | Package installation | low | accept | No dependency installation is planned; existing vendored and locked runtime remains unchanged. |
