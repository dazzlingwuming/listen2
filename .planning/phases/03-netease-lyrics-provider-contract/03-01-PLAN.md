## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Packaged page → WebMessage listener | Untrusted JSON crosses the exact appassets main-frame/origin gate. |
| Native client → NetEase provider | External provider data and authorization state cross an HTTPS, redirect-free, bounded route policy. |
| Native reply → page | Provider bodies and transport material must collapse into safe typed DTOs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Elevation of privilege | `AndroidRpcContract` / `AndroidHttpBridge` | high | mitigate | Exact operation/payload keys, trusted main frame/origin, native route construction, and rejection of all caller transport fields. |
| T-03-02 | Tampering | Request identity and terminal registry | high | mitigate | Bind request ID, page epoch, selection revision/token; cancel active work and accept only first terminal settlement. |
| T-03-03 | Information disclosure | `NetEaseResponseMapper` | high | mitigate | Allow-listed DTO projection plus tests scanning replies/diagnostics for transport, provider-body, credential, and path material. |
| T-03-04 | Denial of service | Provider transport | medium | mitigate | Bounded payload/body/rows/text, deadline, cancellation, no redirect, and finite retry only for classified transient failures. |
| T-03-SC | Tampering | Package installation | low | accept | No package-manager install exists in this plan; pinned project dependencies remain unchanged. |
</threat_model>
