New closed contracts created by this plan:
- Native module name: Listen2OfflineAudio. Public methods: listDownloads(), enqueueDownload(track), cancelDownload(operationId), retryDownload(source, trackId), removeDownload(source, trackId), clearDownloads(), resolveVerified(source, trackId), invalidate(source, trackId), addListener(eventName), and removeListeners(count).
- enqueueDownload accepts only source, trackId, title, artist, and optional album/durationMs. It rejects unknown keys and never accepts a URL, header, cookie, token, filesystem path, content URI, or caller-selected host.
- Native catalog events and listDownloads return a sanitized snapshot containing usedBytes, quotaBytes, and entries whose only fields are operationId, source, trackId, title, artist, status, downloadedBytes, totalBytes, errorCode, and updatedAt. No transport candidate, content URI, digest, or storage location is part of the Redux-facing shape.
- resolveVerified is the only transient content-URI handoff. It returns {status: hit, uri, mimeType} or {status: miss|corrupt}; offlineAudio.ts passes a hit directly to TrackPlayer and never dispatches it.
- isOfflineDownloadEligible(track) is true only for a non-local NetEase or Kugou Track with a valid semantic provider ID.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| React Native UI → native module | Untrusted JavaScript values cross into privileged network, storage, cancellation, and content-provider capability. |
| Native transport → provider/CDN | Remote status, redirects, lengths, types, bodies, and bytes are untrusted until source-specific policy and integrity checks pass. |
| Partial/catalog files → verified media | Process death, cancellation, disk exhaustion, catalog damage, and byte corruption must not make incomplete content playable. |
| Content provider → TrackPlayer | A transient content URI crosses to the native playback service while the underlying path and catalog remain private. |
| Native catalog event → Redux/UI | Only bounded semantic status may cross; transport and storage details must remain native-private. |
