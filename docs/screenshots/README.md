# README 截图指南

主 README 已预留截图布局。完成截图后，把图片保存到当前目录，并删除根目录 `README.md` 中 `SCREENSHOTS:START` 和 `SCREENSHOTS:END` 所在的 HTML 注释标记即可显示。

## 推荐截图

| 文件名                   | 建议内容                                                             | 建议比例                |
| ------------------------ | -------------------------------------------------------------------- | ----------------------- |
| `now-playing-dark.webp`  | 现代黑播放详情页，显示圆形封面、明显的实时频谱、当前歌词和新版播放栏 | 16:10，建议 1600 × 1000 |
| `library-dark.webp`      | 现代黑音乐库或歌单页，显示侧边栏、歌曲列表和底部播放栏               | 16:10                   |
| `now-playing-light.webp` | 同一首歌的现代白播放详情页，用来展示主题一致性                       | 16:10                   |
| `lyrics-search.webp`     | Bilibili 歌曲的歌词搜索弹窗，展示多个准确候选和来源标签              | 4:3 或 16:10            |
| `desktop-lyrics.webp`    | 桌面歌词同时显示原文与翻译，背景保留少量桌面环境                     | 16:9                    |

## 拍摄建议

- 优先使用有正规封面、歌名与作者信息的 Bilibili 音乐内容。
- 播放详情页应在歌曲起伏明显的位置截图，让实时频谱有清晰层次。
- 双语歌词选择一首确实存在官方或人工翻译的外语歌曲。
- 截图前隐藏调试工具、浏览器地址栏、个人头像、书签、通知和其他隐私信息。
- 所有截图尽量使用相同的窗口尺寸，避免 README 中图片高度跳动。
- WebP 质量 85–90 通常可以兼顾清晰度和仓库体积；单张尽量控制在 1 MB 以内。

## 可选补充

如果后续准备 GitHub Release，还可以增加：
