# 外观与 Windows 优化交付记录

基线：`59af268`（2.35.1）。验证日期：2026-10-11。此版本为本地实现，未发布 GitHub Release。

## 使用

在设置的「主题」区域选择现代白、现代黑、樱花来信、薄荷放学后、星夜电台。旧用户保留现有主题，新用户默认樱花来信。角色插画可以关闭，主题和动态效果分别保存。

- **均衡**：Windows 默认；频谱最高 30fps、Canvas DPR 最高 1.5，取消大面积实时模糊和持续装饰动画。
- **高画质**：macOS 默认；频谱最高 60fps、DPR 最高 2。
- **减少动态**：停止装饰与频谱动画，继续播放音频、更新进度与歌词。系统减少动态偏好优先。

三套主题共用功能组件：樱花采用左右分栏，薄荷采用横幅与下方歌词，星夜采用夜景电台构图。窄窗口或可用高度不足时收起角色，优先保留操作。

## 修复与接口

- 新增 `Listen2Appearance` 管理主题目录与动态预算，主题变化只更新样式，不重建播放控制器。
- `MediaService.searchLyrics(track, query, { force, onUpdate })` 返回 `{ promise, cancel }`；快照包含 `candidates / sources / pending`。原数组搜索接口保留。
- 手动搜索取消候选评分门槛，并去除视频时长对手动检索的影响；自动匹配维持原置信度要求。
- QQ、网易云、LRCLIB、酷我分别显示成功、无结果、超时、不可用、返回异常。部分来源失败不清空成功候选；失败不缓存为无结果。有效空结果缓存 60 秒，重试绕过缓存。
- 最多三个来源任务、三个歌词 HTTP 请求并发；HTTP 超时 8 秒、整次检索 12 秒。关闭面板、切歌或新搜索后取消旧请求，并过滤迟到结果。
- Electron 的 `lyrics:request / lyrics:cancel` 只服务主窗口；请求限于七个固定 HTTPS 端点、禁用重定向、限制响应大小、随取消信号中止。没有关闭网页安全限制。
- 歌曲搜索、歌单、播放队列使用可视区域渲染；重复歌曲按原始行索引保留，原行操作与拖放指令继续使用，打开队列能定位当前歌曲。
- 频谱在视口外、隐藏窗口、关闭详情或减少动态时停止循环；歌词滚动任务可取消，避免同时叠加。
- **Windows 缓存修复**：`fsync` 不能作用于只读句柄（实测返回 `EPERM`）。音频缓存和歌词缓存改用 `r+` 句柄同步，恢复持久化。

## 验证结果

### 自动化与界面

- `node --test app/test/*.test.js`：69 项通过。
- `npm test --prefix app/listen1_chrome_extension`：现有前端测试链全部通过，包含播放恢复、随机队列、歌词翻译、缓存、音效和播放栏。
- 修改的前端 JavaScript 通过仓库 ESLint 配置检查。
- 最终 ASAR 包中抽查 54 个源码/样式/素材文件，内容与工作区一致；通过同版本 Electron 加载包内主进程与页面，默认主题和图片正常，打包代码实网搜索「晴天 周杰伦」返回 18 个候选。未执行安装程序。
- 浏览器检查五主题在 1440×900、1280×720、1024×576、853×480 下的主要控件边界；后两种为 1280×720 在 125%/150% 缩放下的等效 CSS 空间，不是实际 OS DPI 验证。
- 5000 首重复 ID 歌曲的列表只创建约 24 个可见行，滚动到第 1552 行附近后仍维持 24 行，单行高 64px。
- Electron 实例中连续切换主题/播放页 30 次，控制器 ID 保持不变、Canvas 数量保持 2，手动歌词选择不丢失；重新加载后缓存仍为手动歌词。

### 歌词实网检查

Windows Electron 32.3.2，通过真实 IPC 通道测试：晴天、稻香、七里香、红豆、Hello、Yellow、Yesterday、Shape of You、Lemon、夜に駆ける、アイドル、First Love。**12/12 查询返回可选歌词**。

QQ 来源在本次网络环境中全部不可用；网易云 11/12、LRCLIB 11/12 查询返回候选，酷我部分查询为空。错误按来源显示，其他来源仍可用。这不是所有歌曲均能找到歌词的保证，也不自动保证翻唱/现场版本的时间轴一致。

### 性能对照

设备：Windows 11 专业版 10.0.26200，Ryzen 5 9600X，RTX 5070，2560×1440 约 120Hz 显示环境。

使用独立 Chromium 进程、1440×900 视口、相同现代黑播放页、相同本地生成的循环 WAV，Web Audio 分析状态为 `live`；外部网络关闭，音频输出静音但分析持续。每组运行 3 次，每次 30 秒，取中位数。

| 指标 | 基线 | 均衡模式 |
| --- | ---: | ---: |
| 30 秒内两块频谱 Canvas 绘制次数 | 7200 | 1800 |
| 渲染主线程 TaskDuration | 5.675s | 4.098s |
| rAF 帧率 | 119.99fps | 120.02fps |
| 帧间隔 p95 | 8.4ms | 8.4ms |
| 超过 50ms 的长任务 | 0 | 0 |

绘制次数下降 **75%**，主线程任务时间下降约 **28%**。rAF 帧率表示浏览器调度，频谱自身按 30fps 绘制。此测试不是整机 CPU 利用率，也不是低配置 Windows 设备的帧率承诺。

未覆盖：macOS 实机、低配置 Windows、真实 OS DPI、长时间内存泄漏曲线、MV 实网播放。上述项目仍需目标设备回归。

## 构建与后续维护

```powershell
npm ci
npm ci --prefix app/listen1_chrome_extension
npm test --prefix app/listen1_chrome_extension
node --test app/test/*.test.js
npm run dist:win
```

当前系统解压 winCodeSign 工具时缺少创建符号链接的权限，因此本地交付使用 `npm run dist:win:unsigned`。此命令关闭可执行文件签名与资源编辑，不修改系统权限；适合本地验证，不代替正式签名发布。
