# 年度回响入口点击无响应修复

- 目标:修复桌面端(macOS)顶部导航栏“年”图标真实鼠标点击无反应;更新 README(含用户实机截图);更新 Mac 安装包与 Release。
- 状态:修复与本地验证完成,待合并与发布。最后更新日期:2026-11-03

## 已确认事实
- 现象:同一排其他图标可点,仅“年”(`.annual-recap-entry`)真实点击无反应。程序触发 `click()` 正常,年度回响页面与数据均正常(实机 CDP 调试,2026-11-03)。
- 原因:“年”位于 `-webkit-app-region: drag` 的 `.navigation` 内,未显式标记 `no-drag`,真实点击被拖动区域吞掉。
- 验证:先在运行实例中注入 no-drag 样式,用户实点生效;再用修复后的源码(origin/main ac7fc73 + 本改动)启动,未注入任何样式,用户实点生效。

## 改动
- `app/listen1_chrome_extension/css/redesign.css`:`.navigation .annual-recap-entry` 及其子元素 `-webkit-app-region: no-drag !important`。
- 新增 `app/test/annualRecapEntryDrag.test.js` 与 `npm run test:annual-recap`(已确认无修复时失败、有修复时通过)。
- README:v2.35.7 更新说明、年度回响小节加入用户截图 `docs/screenshots/annual-recap-user.webp`、测试命令。
