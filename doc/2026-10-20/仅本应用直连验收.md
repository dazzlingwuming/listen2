## 原生与界面验收

使用独立 profile 的真实 Electron，未读取用户 cookie 或密钥。默认与 updater 两 session 从系统代理切换为 DIRECT；网易与酷狗均解析为公网地址，同轮公开匿名搜索 HTTP 200，LRCLIB 查询 HTTP 200。恢复后两 session 重新跟随系统代理，解析回到原 Fake-IP 路线。

渐进媒体补测取得一首公开免费结果的动态 CDN 地址：解析 8/8 公网，Range 请求 HTTP 206、Content-Range 存在、读取 1024 字节，0 次重定向。最初探针因手写 HTTPS Referer 与 HTTP 媒体请求的策略组合收到 ERR_BLOCKED_BY_CLIENT；移除探针 Referer 后成功，没有为此修改产品安全策略或媒体 header。完整音频输出和所有平台歌曲仍不属于自动化覆盖结论。

CUA 在隔离真实应用中确认按钮等待禁用、成功回执、恢复入口和范围说明可见。安全读取独立存储确认保存生效；实际主程序冷启动观测 saved enhanced=true、双 session DIRECT、网易 DNS 2/2 公网。真实安装保留既有歌单、歌词和翻译设置；用户已确认使用正常。
