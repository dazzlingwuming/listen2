- LRCLIB 使用实际版本与项目地址标识客户端；收到 429/503 时遵循数字或日期格式的 Retry-After，原有 8 秒单次时限内最多重试一次。每次请求完成后至少间隔 400ms，较长服务器冷却跨后续搜索保留，其他来源仍可并发。规范依据：[LRCLIB 官方说明](https://lrclib.net/docs)。

## FX 增强

沿用现有 FX 入口和七个非原声预设，舒适均衡仍为单开关。原声、用户音量/静音、DSP 核心和切换时序未改变；正常 worklet 使用统一电平校准，回退路径另保留安全余量。

| 预设     | 合成输出相对原声的方向性变化                    |
| -------- | ----------------------------------------------- |
| 重低音   | 40Hz 约 +5.75dB，180Hz 约 +2.72dB               |
| 清晰人声 | 40Hz 约 -15.90dB，2.6kHz 约 +3.28dB             |
| 空灵     | 12kHz 约 +3.69dB                                |
| 温暖     | 40Hz 约 +2.99dB，12kHz 约 -1.46dB               |
| HiFi     | 40Hz/3.2kHz/12kHz 约 +2.14/+2.25/+1.71dB        |
| 3D       | 立体声 side/mid 比增加约 1.54dB，单声道保持居中 |
| 夜间     | 12kHz 约 -2.70dB，保留原有 -20dB/2:1 压缩力度   |

普通代表样本稳态约 -16 LUFS，与原声差小于 0.001 LU。高峰重低音压力样本约 -19.60 LUFS/-1.49996dBTP，受峰值保护限制，不能保证所有素材到 -16 LUFS。夜间曾试更强压缩但因切换偏差扩大而拒绝；最终 400ms 平均偏移 +1.397dB，同素材旧值 +1.346dB，>2dB 持续 130ms（旧 120ms），不承诺每一瞬间等响。

计量使用此前经独立参考校准且本轮未变的产品 analyzer，本轮不是新一次独立标准计量。完整生产页面的真实 DOM 预设点击、当前 Howl/source/滤波器连通均在匿名合成环境通过；不等同于用户安装版、真实歌曲或声卡听测。
