# 播放页 UI 隔离验收证据

整理日期：2026-10-26（America/Los_Angeles）

## 结果摘要

已将 7 组代表截图及对应 DOM/布局 JSON、拖动行为 JSON 和 3 份关键校验摘要从登记 scratch 复制到本目录；逐文件 SHA-256 与来源一致。证据来自隔离的真实 Electron 主进程与 Listen1 renderer，使用独立测试 profile、假歌曲 metadata 和本地图片，不播放音频，不访问/修改用户 profile。此轮未重跑测试、未启动应用。

- 日主题详情页：1367×684 有歌词时 caption 与 transport shelf 间距 23.20px；1367×953 为 43.52px。频谱和 caption 均在左侧可视区，页面无水平溢出。
- 1367×684 无歌词版的 caption-to-shelf 间距为 36.70px；1000×670 默认主题为 79.50px。底栏 seek、音量与双侧时间位于控制栏内。
- 600×670 日主题普通底栏：seek 89.06px、音量轨 52px、歌曲文字可见宽度 83.375px；相关控制和两侧时间在栏内。
- 600×420 本轮刷新复核：普通态文字可见 83.375×18px，展开态 76.42×18px；seek 分别 89.06/67.06px，音量轨 52px，摘要检查均通过。该证据替代旧的 600×420 截图/摘要，本目录没有保留旧图。
- 真实 `draggable-bar` 鼠标拖动用录制器替代 `l1Player.seek`：拖动中预览为 `1:00:00`、`changing=true`、进度 100；松开后 `changing=false`，只记录一次 seek `[1]`，未播放音频。
- Mint 截图只验证歌词背景透明和文字/工具栏对比度；该主题隐藏左侧舞台，因此不能据此声称频谱布局通过。图片主题歌词容器测得透明背景、无背景图/边框/阴影；有歌词样本保留高亮文字及搜索/翻译/时间偏移按钮。

## 证据范围与限制

- PNG 为隔离 Electron 中真实应用 renderer 的截图，不是手工重绘；相邻 JSON 记录 viewport、几何、overflow 和主题校验。歌词及曲目为夹具内容。
- 不包含真实音乐解码、声谱响应、登录、线上歌词抓取或真实音量变更验证；拖动动作只覆盖 DOM directive/controller 路径并替换 seek 副作用。
- 已阅读 scratch 中 `verification-summary.json`、`metadata-verification-summary.json`、`minwidth-utility-verification-summary.json`、`transparent-lyrics-verification-summary.json` 与 `real-directive-drag.json`。通用早期 summary 和旧 minwidth 600×420 数值未复制，避免与 2026-10-26 刷新的 minheight 复核冲突。保留的 `minheight-metadata-verification-summary.json` 是新的 600×420 普通/展开元信息校验。
- 本目录未包含失败调试日志；600×420 最新复核已完成，不再标为待复核。
